# Phase 0 — Requirements

Status: complete

Goal: enough information and enough decisions to start building.

## Functional

- R0.1 Recover the content of the old resume site. The data must end up as a
  typed, normalized document rather than a copy of the old shape.
- R0.2 Record a resume revision targeting the current market and the intended
  narrative: frontend developer broadening into systems work, returning to
  React with LLM integration, moving toward AWS solutions architecture.
- R0.3 Capture every design decision with its reasoning, so the choice can be
  revisited without re-deriving it.

## Constraints

- R0.4 No invented experience. Anything unverified is a bracketed placeholder
  rather than a plausible guess.
- R0.5 No private contact details in the repo. The old site shipped a phone
  number in a public client bundle.
- R0.6 Decisions that block Phase 1 must be closed, not deferred.

## Out of scope

- Any AWS resource, any Rust code, any visual design work.
